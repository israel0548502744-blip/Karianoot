# קריינות

אפליקציית אנדרואיד שהופכת טקסט בעברית לקריינות, בלי אינטרנט. המודלים רצים בתוך הטלפון.

**להתקנה:** בעמוד [Releases](../../releases/latest) מורידים את `Karianoot.apk` ופותחים בטלפון.
המודלים (בערך 700MB) יורדים מתוך האפליקציה, פעם אחת.

מודלים: BlueTTS (MIT), RenikudPlus (Apache-2.0). פרטים במסך "אודות" באפליקציה.
